The purpose of this Object Oriented Programming homework assignment is to complete 3 separate tasks.

1. Create a Roman Numeral Converter
  The purpose of this program is to convert a user input to Roman Numerals. The input must be between 1 through 90.

2. Create an alphabetical Name Sorter
  The point of this program is to take 3 user inputs, specifically "names" from the user, then display them in alphabetical order. If they are already in order, nothing changes.
  However, if the names match the first letter (i.e Amy and Angelica), the program will then check the second letter, then third, and so on.

3. Create a Troubleshooter program
  The intended use of this program is to create a basic program that utilizes boolean functions to successfully help a user fix an error with their system. This is moreso a "fake"
  scenario. So it is kind of silly in a way, because if the program fails to find the issue it basically tells the user to buy a new router.
